# Árvore Genealógica — Família Dias, Soares & Amorim

Projeto estático publicado no GitHub Pages com uma versão premium da árvore genealógica familiar.

## Arquivos
- `index.html` — página principal interativa
- `arvore-genealogica-jorge.pdf` — versão em PDF para download
- `.nojekyll` — garante publicação direta no GitHub Pages

## Publicação local
Abra `index.html` em um navegador ou sirva a pasta com um servidor estático.
